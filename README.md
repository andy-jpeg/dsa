What Is My Next Game?

The program does require you to have SMFL downloaded on your device. To use the program all you need to do is pull the repository! After doing so, and assuming you have SMFL downloaded, you should be able to build the program and run it on the IDE of your choice! The program REQUIRES you to input how many game recommendations you would like, it will not run unless you do so. Changing any other category options is optional.
